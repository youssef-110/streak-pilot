Your commits, on a schedule you set.

Choose a repository and the times of day. Streak Pilot makes real commits at those minutes, every day, from the cloud. Your computer can stay off.

  1. 1

    Sign in with GitHub

    Streak Pilot asks for repository access so it can commit on your behalf. Nothing else.

  2. 2

    Pick or create a repository

    Use one you have, or let Streak Pilot create a private one just for this.

  3. 3

    Set your times

    Add as many daily slots as you like, choose the days and how many commits each slot makes.

Exact to the minute

Each account has its own timer in the cloud, so a 09:15 slot commits at 09:15 in your time zone. Add a random delay if you prefer it to look less regular.

Your token stays sealed

The GitHub token is encrypted before it is stored and is only used to write one file, .github/streak-pulse.txt, in the repository you pick.

Leave whenever you want

Pause your schedule with one switch. Deleting your account removes your data and revokes GitHub access.

What GitHub counts

GitHub decides what appears on your graph: commits must land on the default branch, and private repositories only show if you enable private contributions on your profile.

Streak Pilot is free and open source. Use it in line with GitHub's terms.
