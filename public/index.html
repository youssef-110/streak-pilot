Sign in

Keep your contribution graph green, every day.

Pick a repository and the times of day. Streak Pilot makes real commits at those minutes from the cloud, so your computer can stay off.

Sign in with GitHub Free. Takes about a minute to set up.

Set up once

  1. Sign in with GitHub

    Streak Pilot asks for repository access so it can commit as you. It never reads your code.

  2. Choose a repository

    Use one you already have, or create a fresh one from the dashboard. Commits only change .github/streak-pulse.txt.

  3. Add your times

    As many daily times as you want, on the days you pick, with 1 to 20 commits each. Add a random delay if you want them to look less regular.

Good to know

Does my computer need to be on?
No. Every account has its own timer in the cloud that fires at the exact minute, in your time zone.
Will the squares turn green?
Yes, when the commits land on the default branch of a public repository. For a private repository, turn on private contributions in your GitHub profile settings.
How is my GitHub access stored?
Your token is encrypted before it is saved and is used only to write the pulse file in the repository you choose.
Can I stop it?
Pause the schedule with one switch, or delete your account. Deleting erases your data and revokes Streak Pilot's GitHub access.
